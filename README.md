# M3U Merger

Утилита для объединения нескольких M3U-плейлистов в один с удалением дублирующихся ссылок.

## Возможности

- Объединение нескольких M3U/M3U8 файлов
- Удаление дублирующихся потоков (по URL)
- Поддержка wildcards (`*`) для выбора файлов
- Рекурсивный обход директорий
- Сохранение метаданных каналов (#EXTINF)
